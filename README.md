# .github

Organization profile and shared community health files for [EnGenius Technologies](https://github.com/engeniustech) on GitHub.

| File | What it does |
|---|---|
| [`profile/README.md`](profile/README.md) | The text on the organization homepage, [github.com/engeniustech](https://github.com/engeniustech). |
| [`SECURITY.md`](SECURITY.md) | How to report a security vulnerability. Applies to every repository in this organization that does not have its own `SECURITY.md`. |

Changes to these files are made by the organization owners.
